Type fast, stay out of the way

What you need for everyday Vietnamese typing, and nothing extra.

Telex and VNI

Switch between the two methods from the menu or with a global hot key.

Correct tone placement

Tones go on the final vowel in oa, oe, uy by default (hoá, hoé, huý). English words such as developer pass through unchanged.

Per-app control

Exclude Terminal, code editors or games, and use a hot key to toggle ViGo for the app in front.

Text expansion

Keep a list of abbreviations and replacements, stored locally on your machine.

Private by design

What you type is processed on-device only: no network, no logs, no telemetry. ViGo passes password fields straight through.

Rust core, open source

The composition engine is written in Rust and tested against a reference suite and fuzzing. Licensed GPLv3.

Install

A few steps on each system.

macOS

  1. Open the .pkg and follow the installer, then log out and back in if asked.
  2. Open ViGo; its icon appears in the menu bar.
  3. When prompted, grant Accessibility access in System Settings → Privacy & Security.
  4. Keep the macOS ABC input source selected, then choose Telex or VNI in the ViGo menu.

Windows

  1. Run the .msi and finish the installer.
  2. Go to Settings → Time & language → Language & region, add Vietnamese if needed, then add the ViGo keyboard.
  3. Open ViGo from the Start menu to choose Telex/VNI and hot keys.

Linux

sudo apt install ./vigo-ibus_*.deb
ibus restart

For Fcitx5, install vigo-fcitx5 and run fcitx5 -rd. Then pick ViGo Telex or ViGo VNI in your input-method tool.

FAQ

I type but no Vietnamese appears (macOS)?
  • Check that ViGo is listed and enabled in System Settings → Privacy & Security → Accessibility.
  • The ViGo menu must show Telex or VNI, not Off. The menu bar icon reads VITX or VNI.
  • The app you are using may be on the exclusion list. The icon then shows A.
Why keep the ABC input source on macOS?

ViGo replaces text directly in the app instead of using an underlined composition box, which is the most reliable approach. You do not need to select a ViGo input source in macOS keyboard settings for normal typing.

macOS says the app cannot be opened?

If macOS blocks it for security reasons, open System Settings → Privacy & Security and choose Open Anyway. Only do this for files downloaded from the official Releases page.

Windows shows a SmartScreen warning?

If the installer is not code-signed, Windows may warn you. Make sure you downloaded it from the official Releases page and compare the SHA-256 before choosing Run anyway.

Does ViGo collect what I type?

No. Typed content is processed on-device only: it is not sent over the network and does not appear in logs. You can verify this yourself because the full source is public.

I found a bug in one specific app. Where do I report it?

Open an issue and pick the "App compatibility" form. Share only the shortest key sequence that reproduces it, and never paste private text.

How is ViGo different from NAKL?

ViGo is the successor to NAKL, rewritten around a shared Rust core for macOS, Windows and Linux.

ViGo is released under the GPLv3. ViGo derives from NAKL by Huy Phan. The key handling algorithm and key map are based on xvnkb by Dao Hai Lam.
